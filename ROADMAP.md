## 🎯 1. Миссия и North Star Metric

### Миссия
Дать курьерам и логистическим паркам микромобильности (электровелосипеды, фэтбайки) инструмент маршрутизации, который **гарантирует завершение смены без внезапной разрядки аккумулятора** и минимизирует себестоимость километра доставки.

### 🌟 North Star Metric (Главная метрика)
> **0 инцидентов разрядки батареи посреди маршрута** при сохранении минимального времени доставки.

## 🗺️ 3. Фазы развития продукта (Milestones)

### 📍 ФАЗА 1: Ультимативный навигатор курьера (v1.0) ✅
*Фокус: Идеальный опыт одной смены курьера.*
- [x] Физический движок тягового усилия (Tractive Effort Model).
- [x] Двухмаршрутная оптимизация (Быстрый vs Эко-пологий).
- [x] Мульти-точки доставки (Waypoints) с динамическим сбросом веса.
- [x] Кастомный гараж («Мой электробайк»).
- [x] Экспорт маршрута в GPX.
- [x] Умный буфер обмена (ссылки 2ГИС, Яндекс, Google, координаты).
- [x] Автоматическая синхронизация погоды (Open-Meteo).

---

### 🧠 ФАЗА 2: Умная логистика, физика и Backend-First (v2.0) ✅
*Фокус: Алгоритмы экономят силы и батарею, единый источник математической истины.*
- [x] **Энерго-ориентированный коммивояжер (Energy-Aware TSP):** перестановка точек для экономии батареи до 22.5%.
- [x] **Поправка на дорожное покрытие и сезон ($C_{\text{rr}}$):** матрица сопротивления качения (сухо/дождь/снег).
- [x] **Архитектура Backend-First:** FastAPI как центральный вычислительный узел.

---

### 📱 ФАЗА 2.5: Mobile-First UI/UX и жестовая шторка (v2.5) ✅
*Фокус: Эргономика экрана смартфона, обзор карты 85% и жестовая 3-уровневая шторка.*
- [x] 3-уровневая шторка (`Peek ~72px`, `Half ~45vh`, `Full ~85vh`) без потери состояния маршрута.
- [x] Компактный плавающий остров управления 48px.
- [x] Боковой стек плавающих кнопок FAB (GPS, отмена, сброс).

---

### 🎨 ФАЗА 2.6: Модернизация фронтенда, темы и интерактивность (v2.6) ✅
*Фокус: Чистая модульная архитектура, тёмная тема для ночных смен, неблокирующий UX.*
- [x] **Модульная структура:** разделение монолита на `index.html`, `app.js` и `styles.css`.
- [x] **Dark Mode & Light Mode:** автоматическое и ручное переключение тем с сохранением в `localStorage`.
- [x] **Интерактивный профиль рельефа:** hover-синхронизация графика высоты с точкой на карте.
- [x] **Современный Toast & Modal UX:** замена `alert()` и `prompt()` на всплывающие тосты и модалки.
- [x] **Безопасность:** экранирование пользовательского ввода и геоданных против XSS.

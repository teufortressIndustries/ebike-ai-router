# AI-оптимизатор маршрутов для электровелосипедов 🚲🔋

Проект для расчета расхода батареи электротранспорта микромобильной логистики с учетом геометрии маршрута, перепадов высот, веса груза и погодных условий.

## Стек технологий
* **Backend:** FastAPI, Python
* **Machine Learning:** scikit-learn (RandomForestRegressor)
* **Frontend:** Streamlit, Folium
* **Гео-данные:** OpenRouteService API

## Архитектура решения
1. `train_model.py` — генерация синтетического датасета и обучение ML-модели.
2. `main.py` — REST API для интеграции с картами и прогнозирования на лету.
3. `app.py` — пользовательский интерфейс для визуализации маршрута.

## Как запустить локально
1. Клонируйте репозиторий.
2. Установите зависимости: `pip install -r requirements.txt`
3. Обучите модель: `python train_model.py`
4. Запустите бэкенд: `uvicorn main:app --reload`
5. Запустите интерфейс: `streamlit run app.py`

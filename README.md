# E-Bike AI Route & Energy Optimizer 🚲🔋

Интеллектуальная система маршрутизации и оптимизации энергопотребления для курьерской микромобильной логистики. 

В отличие от стандартных навигаторов, система рассчитывает расход аккумулятора на основе **тяговой физической модели (Tractive Effort Model)** с учетом геометрии трека, набора высоты, аэродинамики курьерского короба, полезного веса и температурной деградации Li-Ion аккумуляторов.

---

## ⚡ Ключевые возможности

* **Выбор и сравнение альтернативных маршрутов:** 
  * ⚡ **Самый быстрый маршрут** (минимальное время доставки).
  * 🍃 **Эко-маршрут** (минимизация набора высоты и расхода Вт·ч).
* **Честная физика расхода энергии (`physics.py`):**
  * Трение качения колес по асфальту ($F_{\text{roll}} = C_{\text{rr}} \cdot m \cdot g$).
  * Аэродинамика курьера с объемным коробом ($F_{\text{aero}} = \frac{1}{2} \rho C_d A v^2$).
  * Работа преодоления гравитации при подъемах ($W_{\text{climb}} = m g \Delta h$).
  * Влияние отрицательных температур на доступную емкость Li-Ion аккумуляторов (18650 / 21700).
* **Пресеты электровелосипедов:**
  * Курьерский стандартный (Minako / «Колхозник» 48V 15Ah — 720 Вт·ч).
  * Курьерский дальнобойный (60V 20Ah — 1200 Вт·ч).
  * Городской компактный (36V 10.4Ah — 375 Вт·ч).
* **Интерактивный веб-интерфейс (Streamlit + Folium):**
  * Выбор точек старта и финиша в один клик по карте.
  * Визуальная индикация безопасности (зеленый / желтый / критический заряд).
  * Детализация энергозатрат (качение / воздух / гравитация).

## 🛠️ Стек технологий

* **Backend:** FastAPI, HTTPX (асинхронный клиент), Pydantic v2.
* **Физический расчет:** NumPy, Python Dataclasses.
* **Frontend:** Streamlit, Folium, `streamlit-folium`.
* **Гео-данные и высотный рельеф:** OpenRouteService API (3D Elevation GeoJSON).

## 🚀 Быстрый старт

### 1. Клонирование и установка зависимостей
```bash
git clone https://github.com/qlmiran/ebike-ai-router.git
cd ebike-ai-router
pip install -r requirements.txt
```

### 2. Настройка API-ключа
Создайте файл `.env` на основе `.env.example`:
```bash
cp .env.example .env
```
Укажите ваш бесплатный ключ OpenRouteService в `.env`:
```env
ORS_API_KEY=your_key_here
```

### 3. Запуск сервисов

**Терминал 1 — FastAPI бэкенд:**
```bash
uvicorn main:app --reload
```
Документация Swagger доступна по адресу: `http://127.0.0.1:8000/docs`

**Терминал 2 — Streamlit интерфейс:**
```bash
streamlit run app.py
```
Интерфейс откроется в браузере по адресу: `http://localhost:8501`

## 📡 API Endpoints

* `GET /health` — проверка состояния сервиса и доступных пресетов.
* `POST /optimize` — детальный расчет и сравнение альтернативных маршрутов.
* `GET /optimize` — быстрый расчет для интеграций и тестирования в браузере.

# E-Bike AI Route & Energy Optimizer 🚲🔋

> 📱 **Онлайн-демо без установки (работает со смартфона):**  
> 👉 **[https://teufortressindustries.github.io/ebike-ai-router/](https://teufortressindustries.github.io/ebike-ai-router/)**

Интеллектуальная система маршрутизации и оптимизации энергопотребления для курьерской микромобильной логистики на электровелосипедах.

В отличие от стандартных автомобильных или пеших навигаторов, система рассчитывает расход аккумулятора на основе **тяговой физической модели (Tractive Effort Model)** с учетом геометрии трека, высотного профиля, аэродинамики курьерского короба, веса груза (с динамическим сбросом веса на остановках) и температурной деградации Li-Ion аккумуляторов.

---

## ⚡ Ключевые возможности

* **Современный Mobile-First веб-интерфейс (`docs/`):**
  * Полноценная поддержка **Dark / Light Mode** (удобно для ночных смен курьеров).
  * 3-уровневая жестовая шторка (`Peek`, `Half`, `Full`) без потери рассчитанного маршрута.
  * Интерактивный профиль рельефа с отслеживанием положения курсора на карте.
  * Неблокирующие всплывающие Toast-уведомления и защита от XSS.
* **Умная логистика и мульти-точки:**
  * **Energy-Aware TSP:** оптимизация порядка объезда точек для экономии до 22.5% батареи за счет гравитации и сброса тяжелого груза.
  * Расчет сопротивления качению ($C_{\text{rr}}$) по типам дорожного полотна (асфальт, плитка, брусчатка, грунт) и сезону (сухо, дождь, слякоть/снежная каша).
  * Режим «Туда и обратно» (возврат на базу налегке).
* **Честная тяговая физика (`physics.py`):**
  * Трение качения колес ($F_{\text{roll}} = C_{\text{rr}} \cdot m \cdot g$).
  * Аэродинамика с учетом термокороба и встречного ветра ($F_{\text{aero}} = \frac{1}{2} \rho C_d A v^2$).
  * Работа преодоления уклонов и рекуперация ($W_{\text{climb}}, W_{\text{regen}}$).
  * Потеря емкости Li-Ion батарей на морозе до $-25^\circ\text{C}$.
* **Кастомный гараж курьера («Мой байк»):**
  * Поддержка стандартных пресетов (48V 15Ah, 60V 20Ah, 36V 10Ah) и кастомных сборок (любой вольтаж 36–72V и емкость в Ah).
* **Умный импорт и экспорт:**
  * Распознавание ссылок 2ГИС, Яндекс Карт, Google Maps, сырых координат и текстовых адресов.
  * Пакетный импорт смены (вставка списка адресов).
  * Экспорт маршрута в формат GPX 1.1 для открытия в 2ГИС, Яндекс Навигаторе и OsmAnd.

## 🛠️ Стек технологий

* **Frontend:** Чистый модульный Zero-Build стек (`index.html`, `app.js`, `styles.css`), Leaflet.js, CARTO Voyager Tiles, FontAwesome, Tailwind CSS.
* **Backend:** FastAPI, HTTPX (асинхронный клиент), Pydantic v2, Uvicorn.
* **Физический расчет:** Python Dataclasses, формулы классической механики.
* **Внешние геосервисы:** OpenRouteService API (3D Elevation GeoJSON, Extra Info: Surface), Open-Meteo (погода без API-ключей), Nominatim OSM (геокодирование).

## 🚀 Быстрый старт

### 1. Клонирование и установка зависимостей
```bash
git clone https://github.com/teufortressIndustries/ebike-ai-router.git
cd ebike-ai-router
pip install -r requirements.txt
```

### 2. Настройка API-ключа
Создайте файл `.env` на основе `.env.example`:
```bash
cp .env.example .env
```
Укажите ваш ключ OpenRouteService:
```env
ORS_API_KEY=your_key_here
```

### 3. Запуск сервиса
```bash
uvicorn main:app --reload
```
Приложение будет доступно в браузере по адресу: **`http://localhost:8000/`** (автоматически раздает современный мобильный фронтенд из каталога `docs/`).  
Интерактивная документация Swagger API: `http://localhost:8000/docs`

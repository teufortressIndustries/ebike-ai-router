# 📱 Спецификация мобильного интерфейса (Mobile UI/UX Design Specification)

> **Статус:** Принято в разработку (Фаза 2.5: Mobile-First UX Redesign)  
> **Целевые устройства:** Смартфоны курьеров (360×640px – 430×932px), держатели на руле электробайка, управление одной рукой / в перчатках.

---

## 🛑 1. Анализ текущих проблем интерфейса (UX Audit / As-Is)

Текущий веб-интерфейс создавался по принципу «разместить все кнопки сразу на экране», из-за чего на смартфонах возникли критические проблемы эргономики:

1. **Экран перегружен верхними карточками (Viewport Choke):**
   - Шапка приложения (лого + погода + GPS + шестеренка)
   - Строка поиска с бейджем города
   - Лента добавления точек доставок
   - Лента закладок
   - Блок «Туда и обратно»
   - 3-позиционный тумблер дорожного покрытия ($C_{\text{rr}}$)
   - **Итог:** Верхняя панель съедает более **55–60% полезной площади экрана**. Карта оказывается зажата в узкую полоску по центру, курьеру крайне неудобно ориентироваться и ставить точки.

2. **«Фейковая шторка» (Fake Bottom Sheet):**
   - Серый элемент «ручка шторки» (`w-12 h-1.5 bg-slate-300`) на самом деле не является интерактивным слайдером. Он не поддерживает свайпы (`touchstart`, `touchmove`), а работает как обычная кнопка закрытия `onclick`.
   - При клике на ручку или крестик карточка результатов **полностью исчезает** (`hidden`), и на экране снова появляется только плавающая кнопка «Рассчитать».

3. **Потеря состояния рассчитанного маршрута (Lost State):**
   - Если курьер свернул результаты, чтобы посмотреть на карту, **нет возможности вернуть карточку обратно в один клик**.
   - Приходится заново нажимать «Рассчитать маршрут и физику» и ждать повторного ответа от сервера, что раздражает и расходует трафик/лимиты API.

4. **Отсутствие зон досягаемости пальца (Thumb Zone Mismatch):**
   - Ключевые действия распределены по разным углам экрана без учета эргономики управления большим пальцем на ходу.

## 🎯 2. Принципы нового мобильного дизайна (To-Be Vision)

```
┌──────────────────────────────────────────────┐
│  [📍 Караганда ▾]   [🔍 Поиск улицы...] [⚙️]  │ ➔ Компактная плавающая строка (48px)
├──────────────────────────────────────────────┤
│                                              │
│                                              │
│              КАРТА LEAFLET                   │ ➔ 80-85% видимой площади экрана
│         (Свободный обзор трека)              │
│                                              │
│                                   [ ⌖ GPS ]  │ ➔ Плавающие кнопки действий (FAB)
│                                   [ ⚡ Swap ] │
├──────────────────────────────────────────────┤
│ ══════════════ [РУЧКА СВАЙПА] ══════════════ │ ➔ Настоящая шторка (Bottom Sheet)
│ 7.5 км • 18 мин • 92 Вт·ч (-13%) • 🟢 72%    │ ➔ PEEK-режим (компактная полоса)
└──────────────────────────────────────────────┘
```

### Главные правила:
1. **Map-First (Карта — главный экран):** Не менее **80% площади дисплея** должно оставаться открытым для карты. Все управляющие элементы должны быть плавающими («островными») и полупрозрачными с эффектом `backdrop-blur`.
2. **True Bottom Sheet с 3 фиксированными состояниями (Snapping Points):**
   - **Состояние 1: Свернуто (Peek, ~72px):** Всегда видна мини-плашка с ключевой сводкой (`Дистанция`, `Время`, `Вт·ч`, `Остаток батареи %`). Не перекрывает карту.
   - **Состояние 2: Половина (Half-Expanded, ~45vh):** Открывает график высот, карточку дорожного покрытия и предупреждение о безопасности.
   - **Состояние 3: Полный экран (Full-Expanded, ~85vh):** Полная детализация по отрезкам, таблица затрат энергии (качение/воздух/подъемы) и кнопка экспорта GPX.
3. **Плавные жесты перетягивания (Touch Gestures & Physics):**
   - Поддержка перетягивания пальцем вверх и вниз с инерцией (velocity tracking).
   - Плавная анимация через CSS `transform: translateY(...)` без лагов.
4. **Сворачиваемая верхняя панель (Smart Top Bar):**
   - Единая компактная строка поиска (город + ввод адреса + кнопка меню).
   - Точки доставок и селектор покрытия прячутся в выдвижной компактный аккордеон или открываются только по тапу.
5. **Сохранение активного маршрута:**
   - Рассчитанный маршрут хранится в памяти: шторку можно свернуть в компактный Peek или снова развернуть в любой момент без повторного запроса к бэкенду.

## 📐 3. Архитектура компонентов интерфейса

### А. Плавающая верхняя строка (Header Bar)
* Высота: 48px, плавающий `glass-card` с отступом 12px от краев экрана.
* Элементы в один ряд:
  - Кнопка выбора города: `[📍 Крг ▾]`
  - Поле быстрого поиска / вставки: `[🔍 Адрес или ссылка...]`
  - Кнопка буфера: `[📋]`
  - Кнопка статуса API / меню: `[⚡]`

### Б. Островная панель мульти-заказов (Waypoint Strip)
* По умолчанию отображается в компактном виде: горизонтальный скролл цветных чипсов:
  `[🟢 Старт] ➔ [🔵 #1] ➔ [🟣 #2] ➔ [➕ Добавить]`
* Кнопка оптимизации порядка: маленькая плавающая кнопка `[✨ TSP]` рядом с чипсами.
* Тумблер покрытия: лаконичный сегментированный контрол (`☀️` / `🌧️` / `❄️`) на 28px высоты.

### В. Настоящий жестовый Bottom Sheet
* **Анатомия шторки:**
  - Верхняя плашка (Header / Drag Handle) высотой 24px с визуальной полоской `w-12 h-1.5`.
  - Зона краткой сводки (Mini Dashboard, 48px): 4 компактных колонки:
    - 📍 `7.5 км`
    - ⏱️ `18 мин`
    - ⚡ `92 Вт·ч`
    - 🔋 `72% (🟢 Безопасно)`
  - Контентная часть (Scrollable Body):
    - График набора высоты (SVG Elevation Profile).
    - Карточка дороги: тип покрытия, $C_{\text{rr}}$, погодные рекомендации.
    - Список отрезков доставок (Legs) с цветными маркерами и весом груза на каждом этапе.
    - Детализация сил (трение качения, аэродинамика термокороба, подъемы).
    - Кнопка `[📥 Экспорт в GPX для навигатора]`.

### Г. Плавающие функциональные кнопки (FAB Stack)
* С правой стороны экрана над шторкой:
  - `[ ⌖ ]` — Центрирование на текущей GPS-позиции.
  - `[ 🗺️ ]` — Переключение типов карты / слоев.
  - `[ ⚡ ]` — Слой обменников батарей и зарядных станций (Фаза 2.5).

## 📋 4. Технический план реализации редизайна (Milestone UI 2.5)

1. **Создание touch-компонента Bottom Sheet:**
   - Написание чистого JavaScript-класса `BottomSheetController` (~150 строк) без тяжелых сторонних библиотек.
   - Обработка `touchstart`, `touchmove`, `touchend` с привязкой к `translateY`.
   - Точки привязки (Snap Points): `collapsed` (72px от низа), `half` (45% экрана), `expanded` (85% экрана).
2. **Компактизация верхней панели управления:**
   - Объединение поиска, города и буфера обмена в ультратонкую строку.
   - Сворачивание второстепенных элементов в компактные выпадающие панели.
3. **Бесшовное переключение состояний маршрута:**
   - При расчете маршрута шторка автоматически открывается на уровень `half`, показывая главные цифры и профиль высот.
   - При свайпе вниз шторка садится в состояние `peek` (нижняя полоска), оставляя весь экран для комфортного изучения трека на карте.
4. **Тестирование на мобильных экранах:**
   - Проверка во Viewport-эмуляторе Chrome/Firefox под размеры iPhone 13/14 (390px), Android-бюджетники (360px) и планшеты.
